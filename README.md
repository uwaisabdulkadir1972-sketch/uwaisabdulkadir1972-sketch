# Uwais Ahamed

Engineering Systems and Design undergraduate interested in AI engineering, automation and data. I enjoy building practical systems that bring together models, software and analysis.

## Projects

**[Parallel Match](https://github.com/evanyap7/Parallel-Match)** — A football match intelligence application built for the Microsoft × Premier League Inside the Game Hackathon. It compares original and alternate match timelines using paired Monte Carlo simulations, with AI-assisted narration, law explanations and historical context.

**[Multimodal RAG](https://github.com/uwaisabdulkadir1972-sketch/Multi-Modal-RAG)** — A question-answering system for slide decks that combines text and image retrieval with a vision model. Includes an evaluation workflow for retrieval and answer quality.

**[Dengue Routing](https://github.com/uwaisabdulkadir1972-sketch/dengue-routing)** — A routing optimisation project comparing simulated annealing and local search with a mathematical programming benchmark.

**[Stable Matching Optimisation](https://github.com/uwaisabdulkadir1972-sketch/stable-matching-optimization)** — A donor–patient matching model built with Julia, JuMP and HiGHS.
